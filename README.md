# FlowerShop

A modern, responsive landing page for a flower shop built with **React** and **Tailwind CSS**.

## Features

- 🌷 Beautiful hero section with call-to-action
- 🌻 Featured flowers showcase
- 🚚 Support section (delivery, fresh flowers, 24/7 support)
- 🎁 Hot deals promotional banner
- 📸 Instagram gallery
- 📧 Newsletter subscription
- 📱 Fully responsive (mobile, tablet, desktop)

## Tech Stack

- React
- Tailwind CSS
- Vite
